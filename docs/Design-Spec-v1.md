# Processing Screen

Display a progress animation with the following steps:

✓ Reading Document

✓ Detecting Document Type

✓ Extracting Information

✓ Generating Summary

Loading Spinner

---

# Results Dashboard

The Results page should be divided into cards.

Cards:

1. Document Type

2. Summary

3. Important Information

4. Action Required

5. AI Confidence

6. Ask AI

Each card should have:

- White background
- Rounded corners
- Soft shadow
- 24px padding

---

# Chat Section

Bottom input box

Suggested Questions

- What does this report mean?
- Is anything abnormal?
- What should I do next?

Responses should always be based only on the uploaded document.

# Design Goal

The application should look like a professional AI SaaS product rather than a college project.

The interface should be clean, modern, trustworthy, and easy to use.
